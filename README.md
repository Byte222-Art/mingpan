# mingpan · 命盘

**排四柱、算旺衰、起大六壬。每句话都能被查。**

> **BaZi (Four Pillars) + Da Liu Ren CLI.** Every reading cites a classical source and a confidence level — and says out loud what it does not know.
>
> No API key, no network, no account. Pure Python.

## 它能算什么

| 功能 | 命令 | 说明 |
|---|---|---|
| 四柱八字 | `mingpan bazi 2000-12-12 20:00 --lon 121` | 真太阳时修正、节气换月、晚子时换日 |
| 日主旺衰 | `mingpan strength ...` | 得令 40 / 得地 30 / 得势 30，**算法摊开** |
| 大六壬 | `mingpan liuren --at "2026-10-31 21:57"` | 天地盘、四课、三传、十二天将、课体、断课 |
| 断语库 | `mingpan rules` | 50 条自写断语，每条带出处与置信度 |

**没有网页、没有账号、不联网。**

```bash
$ python bin/mingpan.py bazi 2000-12-12 20:00 --lon 121
四柱：庚辰 戊子 甲辰 甲戌

旺衰：72.0 偏旺（得令 34 / 得地 25.0 / 得势 13.0）
```

## 它怎么保证不算错

**1. 排盘是确定的，不靠模型猜。**

节气、真太阳时、晚子时换日都写死在代码里，同一份输入永远出同一张盘。

**2. 起课引擎不是我写的。**

用的是 [`liuren-bench/liuren_core`](https://github.com/arlen-liang/liuren-bench)（MIT）。作者让它通过了 720 课自洽检验，并把九宗门与《六壬大全》逐条对过。

**我自己写过一版六壬引擎，和它对比 200 课只对了 62 课（31%）。我把它弃用了**，原代码留在仓库里当反面记录。

**3. 断语带出处，带置信度。**

写不出出处的条目不进库；拿不准的标"低"。

**4. 敢说不知道。**

从格、化格、流派差异，都明写在输出里。**"这一层我不装"是设计的一部分。**

---

## 它明确不做什么

- **不预测生死、不诊断疾病、不承诺具体结果**
- **不给投资和婚姻决定下结论**
- **不收集任何数据**：不联网、不写日志、不落库

## 安装

```bash
git clone <repo> mingpan

python bin/mingpan.py bazi 2000-12-12 20:00 --lon 121
```

**零第三方依赖**（Python 3.10+）。紫微斗数需要 Node + iztro，不在本 CLI 内。

## 已知问题

**这些是明写的，不是藏着：**

1. **从格/化格未判定** —— 一边倒的盘会被误算成极弱/极旺
2. **六壬断课只到三层** —— 课体、三传走势、初传天将；四课关系、分类取象还没做
3. **没有案例库** —— 判断准不准，目前没有数据支撑
4. **紫微不在 CLI 里** —— 依赖 Node，需要单独装
